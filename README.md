# Temporal Trends in Myocarditis and Pericarditis Incidence in England (2015-2024): the impact of COVID-19 Infection and Vaccination

Code lists and analysis code for **"Temporal trends in the incidence of myocarditis and pericarditis in England, 2015-2024"**, a population-based cohort study using the Clinical Practice Research Datalink (CPRD) Aurum.

## Study overview

This study examines the incidence of myocarditis and pericarditis in England before and during the COVID-19 pandemic (2015-2024), including associations with SARS-CoV-2 infection, COVID-19 vaccination, and dominant variant periods. The study population comprised adults aged 16 years or older registered with contributing general practices in CPRD Aurum.

## Code lists

Clinical code lists used to define comorbidities and exposures are in the [`code_lists/`](code_lists/) directory. All comorbidity code lists use SNOMED CT codes for use with CPRD Aurum.
